# 🌱 Rokuzen
#### Breve introdução:
O projeto tem como foco principal desenvolver uma interface web responsiva para a ROKUZEN, focada em otimizar o atendimento presencial nas unidades. A solução permitirá visualizar em tempo real a ocupação dos postos de atendimento, as escalas dos terapeutas e o status de cada sala, cadeira ou poltrona. Com controles para início e término de sessões, o sistema visa reduzir atrasos, evitar conflitos e melhorar a gestão dos recursos.
